# Материалы проекта UP02.02

UP02.02 — приложение Windows для подготовки таблицы и экспорта отчёта в PDF или Excel. Здесь собраны требования, описание реализации, диаграммы и результаты проверок.

| Материал | Что находится внутри |
| --- | --- |
| [Требования](requirements.md) | Назначение приложения, функции и ограничения |
| [Архитектура и диаграммы](architecture.md) | Устройство программы, ER, Use Case и Sequence |
| [Проверки приложения](testing.md) | Шесть автотестов, покрытие и ручное QA |
| [Порядок разработки](development.md) | Ветки, CI, защита main и подключение pre-commit |
| [Подтверждения работы](evidence.md) | Ссылки на CI, PR, QA, milestone и оставшиеся материалы |
| [Ретроспектива](retrospective.md) | Три результата, два улучшения и одно действие для обсуждения командой |
| [История изменений](../CHANGELOG.md) | Состав выпуска и изменения процесса разработки |

Диаграммы созданы и экспортированы в [diagrams.net](https://app.diagrams.net/). В папке [diagrams](diagrams) лежат редактируемые файлы `.drawio`, векторные SVG и PNG для просмотра. Чтобы изменить схему, откройте соответствующий `.drawio` через «Файл → Открыть из → Это устройство».

В папке [qa](qa) сохранены скриншоты пользователя и отчёты успешного CI. Скриншоты публикуются в исходном PNG без уменьшения размера.
