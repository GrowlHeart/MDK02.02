# Требования к приложению

Приложение нужно для подготовки отчёта по товарам или другим позициям. Пользователь вводит наименование, количество и цену, выбирает оформление и сохраняет результат в PDF или XLSX. PDF подходит для просмотра и печати, XLSX — для дальнейшей работы с таблицей.

## Данные и расчёты

Строка содержит название, целое количество и цену типа `decimal`. Сумма строки равна количеству, умноженному на цену. Итог отчёта равен сумме всех строк. Операции выполняются с проверкой переполнения.

| Значение | Ограничение |
| --- | --- |
| Название позиции | От 1 до 200 символов, не только пробелы |
| Количество | Целое число от 0 до 1 000 000 |
| Цена | От 0 до 1 000 000 000 000 |
| Число знаков после запятой | От 0 до 4 |
| Размер шрифта | От 9 до 18 |
| Шрифт | Arial, Segoe UI или Times New Roman |
| Цвет заголовка | Шесть шестнадцатеричных символов |
| JSON-шаблон при загрузке | Не более 64 КиБ |
| Строки данных на листе Excel | Не более 1 048 572 |

## Функции

1. Добавлять, изменять и удалять строки таблицы.
2. Открывать CSV в UTF-8 с разделителем `;` и заголовком `Наименование;Количество;Цена`.
3. Показывать первые 100 строк CSV, сохраняя возможность экспортировать весь файл.
4. Настраивать название, колонтитулы, шрифт, цвет, точность чисел, фон строк и график Excel.
5. Сохранять настройки в JSON и загружать их обратно.
6. Экспортировать данные в PDF и XLSX, рассчитывать строки и общий итог.
7. Выполнять экспорт в фоне, показывать число обработанных строк и поддерживать отмену.
8. Отклонять неверные данные и пустой отчёт, сообщать об ошибках записи.

Пример CSV:

```csv
Наименование;Количество;Цена
Бумага А4;5;350.00
Ручка;12;45.00
Папка;3;120.00
```

Правильный итог этого примера — 2650 рублей. Для цены допускаются точка и запятая. Название с разделителем заключается в кавычки.

## Нефункциональные требования

- Приложение работает в Windows x64. Для сборки исходников нужен .NET 8 SDK, готовый автономный EXE содержит необходимые компоненты .NET.
- Кириллица должна оставаться читаемой в интерфейсе и экспортированных файлах.
- При работе с большим CSV строки читаются последовательно. Предварительный просмотр ограничен 100 строками, данные графика — первыми 20 позициями.
- Экспорт выполняется через `Task.Run`, чтобы операция не занимала поток интерфейса.
- Готовый отчёт заменяется после успешной записи временного файла. При отмене или ошибке временный файл удаляется.
- Вводимые строки и настройки проверяются перед использованием. Программа работает с локальными файлами, отдельные аккаунты и сервер не предусмотрены.
- Числовые цели по времени и памяти для большого отчёта требуют отдельного замера. Автотест на 100 000 строк подтверждает однократное чтение источника и корректность результата, но не задаёт норматив скорости.

## Ограничения

В программе нет подключения к БД и постоянного хранения отчётов. Ручной ввод сохраняется только в текущем окне; отдельно сохраняются шаблон и экспортированные файлы. График Excel показывает первые 20 позиций. Экспорт пустого набора отклоняется. Для XLSX сверх ограничения одного листа CSV нужно разделить на несколько файлов.
