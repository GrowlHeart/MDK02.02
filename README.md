# Модуль экспорта отчётов в PDF и Excel

Небольшое приложение Windows Forms на C#. Позволяет редактировать таблицу товаров, добавлять и удалять строки, видеть общую сумму и сохранять отчёт в PDF или Excel.

## Запуск

Требуется Windows и .NET 8 SDK. Откройте папку проекта в терминале и выполните:

```powershell
dotnet restore
dotnet run
```

Для восстановления пакетов нужен доступ к NuGet. Также проект можно открыть в Visual Studio 2022 с компонентом разработки классических приложений .NET.

Измените данные в таблице и нажмите «Экспорт в PDF» или «Экспорт в Excel», затем выберите путь сохранения. Количество должно быть целым неотрицательным числом, цена — неотрицательным числом.

Для Excel используется ClosedXML, для PDF — QuestPDF. В коде выбрана лицензия QuestPDF Community; условия её применения следует проверить на сайте проекта.
