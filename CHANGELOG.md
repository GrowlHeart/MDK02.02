# История изменений

Изменения сгруппированы по формату Keep a Changelog.

## [0.1.0] - 2026-11-28

### Добавлено

- Настольное приложение Windows x64 для подготовки отчётов и экспорта в PDF и XLSX.
- Редактирование наименования, количества и цены; расчёт сумм через decimal.
- Шаблоны оформления с сохранением в JSON: название, колонтитулы, шрифт, цвет и точность чисел.
- Потоковое чтение CSV и генерация больших отчётов; предварительный просмотр первых 100 строк.
- Фоновый экспорт, счётчик обработанных строк и отмена операции.
- Оформление Excel: денежный формат, итог, фильтр, закрепление заголовков и печатные колонтитулы.
- Отдельный лист Excel с графиком первых 20 позиций.
- Многостраничный PDF с кириллицей, переносом длинных названий и номерами страниц.
- Шесть автоматических тестов расчётов, форматирования и экспорта.
- GitHub Actions: форматирование, сборка, тесты, покрытие и автономный EXE в артефактах.

### Исправлено

- Приложение и тесты объединены в общей ветке для совместной сборки и запуска CI.
- Номер версии проекта и документация согласованы с выпуском v0.1.0.

### Известные ограничения

- Приложение предназначено для Windows x64; готовый EXE не требует отдельной установки .NET.
- График Excel показывает только первые 20 позиций.
- CSV должен иметь кодировку UTF-8, разделитель `;` и заголовок `Наименование;Количество;Цена`.
- На одном листе Excel помещается не более 1048572 строк данных с учётом заголовков и итога.
- Автотесты не заменяют ручную проверку интерфейса, печати и отображения файлов в Excel.
